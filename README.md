# Descripción general

Este repositorio contiene el desarrollo computacional de un modelo biofísico tipo Hodgkin–Huxley para describir la actividad eléctrica de células piramidales de la región CA1 del hipocampo.

El modelo incorpora la dinámica del potencial de membrana, corrientes iónicas dependientes de voltaje, dinámica de la concentración intracelular de calcio y entrada sináptica, proporcionando una plataforma computacional para estudiar distintos mecanismos que regulan la excitabilidad neuronal.

Actualmente, este repositorio constituye el soporte computacional de la tesis de licenciatura del alumno **Rivaldo Hernández Magdaleno**, desarrollada en la Licenciatura en Física Biomédica de la Universidad Nacional Autónoma de México.

---

# Objetivo del proyecto

El objetivo principal de este proyecto es utilizar un modelo computacional de tipo Hodgkin–Huxley para estudiar cómo distintas combinaciones de parámetros iónicos y sinápticos pueden conservar un mismo patrón de actividad neuronal.

Particularmente, se busca investigar mecanismos de compensación paramétrica inspirados en el fenómeno conocido como *degeneracy*, así como analizar su posible papel frente a modificaciones fisiológicas asociadas al envejecimiento neuronal.

# Características del modelo

El modelo incluye actualmente:

- Modelo tipo Hodgkin–Huxley de cuatro dimensiones.
- Corrientes de sodio, potasio y fuga.
- Dinámica intracelular de calcio.
- Entrada sináptica.
- Integración numérica mediante Python.
- Herramientas para modificar parámetros del modelo.
- Rutinas para visualización y análisis de resultados.
