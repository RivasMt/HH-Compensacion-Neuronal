# HH-Compensacion-Neuronal
Repositorio correspondiente al desarrollo computacional de la tesis "Degeneracy en un modelo neuronal tipo Hodgkin–Huxley". El proyecto emplea un modelo con dinámica de calcio intracelular y entrada sináptica para investigar la actividad neuronal frente a modificaciones en parámetros biofísicos y cambios asociados al envejecimiento.
